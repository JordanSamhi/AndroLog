TITRE
AndroLog: Instrumentation d'Apps Android en Boîte Noire

CATÉGORIE
Présentation d’un outil (15 minutes)

AUTEUR ET ORATEUR
Jordan Samhi
Université du Luxembourg
Contact : jordan.samhi@uni.lu

RÉSUMÉ
AndroLog permet d’ajouter des logs à une application Android à partir de son APK, sans avoir accès à son code source. Il permet de voir quelles parties du code ont été exécutées, d’enregistrer la valeur d’une variable et d’explorer les appels entre méthodes. L’interface permet de choisir où ajouter ces logs, de tester l’APK sur un appareil ou un émulateur et d’analyser les résultats. La présentation utilise une petite application qui reçoit une URL et vérifie si elle est autorisée. Nous montrerons comment voir la valeur reçue par le contrôle, identifier la méthode appelée et retrouver ces informations dans le code. Les rapports peuvent être exportés en HTML et partagés. L’analyse peut aussi être reprise sur une autre machine avec l’APK instrumenté et les logs.

BIOGRAPHIE COURTE
Jordan Samhi est chercheur à l’Université du Luxembourg. Ses travaux portent sur l’analyse de programmes, le génie logiciel et la sécurité des applications Android. Il est auteur et mainteneur d’AndroLog.

MOTS-CLÉS

PRÉREQUIS
Un navigateur suffit pour consulter le rapport HTML fourni. Le paquet de bureau fourni fonctionne sur macOS avec Apple Silicon et comprend Java. Pour instrumenter ou analyser un APK, il faut installer le SDK Android ; pour l’instrumentation, ses Build Tools sont aussi nécessaires. Pour collecter de nouveaux logs, il faut adb et un téléphone Android autorisé pour le débogage USB ou un émulateur. Aucun périphérique spécialisé, abonnement ou logiciel payant n’est nécessaire. Le SDK et les images d’émulateur restent soumis aux licences de leurs éditeurs. Les sources permettent aussi de construire l’interface pour Windows et Linux, mais ces versions n’ont pas été testées pour ce dossier.

PUBLICATION ANTÉRIEURE
AndroLog a fait l’objet de l’article « AndroLog: Android Instrumentation and Code Coverage Analysis », par Jordan Samhi et Andreas Zeller, publié dans FSE Companion 2024, pages 597–601, DOI 10.1145/3663529.3663806. L’outil a été présenté à FSE le 17 juillet 2024. Une prépublication est disponible depuis le 17 avril 2024 (arXiv:2404.11223).
La proposition SSTIC porte sur le même outil, avec un nouveau texte et une démonstration de son utilisation actuelle pour l’audit : interface, trois types de logs personnalisés, capture sur appareil et analyse à partir de l’APK instrumenté et des logs. La couverture et l’existence d’un graphe dynamique ne sont pas présentées comme de nouvelles contributions. Le texte et les figures de l’article ACM ne sont pas reproduits.
